⚙ Синхронизация с GitHub Gist

Что это?

Все данные (пользователи и услуги) могут храниться в вашем приватном GitHub Gist. Это позволит заходить с любого устройства и видеть одни и те же услуги.

Важно: токен хранится только в вашем браузере (localStorage). Не публикуйте его. Для продакшена используйте серверный бэкенд.

1. Создайте GitHub-токен

Зайдите в github.com/settings/tokens/new, выберите scope gist, создайте и скопируйте токен.

2. Введите токен и Gist ID

3. Ручное управление
